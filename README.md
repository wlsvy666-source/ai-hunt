# AI 속의 사람 · 링크로 들어오는 멀티플레이

게임 화면과 중계 서버가 한 프로젝트에 들어 있습니다. 서버를 한 곳에 올리면, 그 주소를 아는 사람은 누구나 같은 방 코드로 같이 할 수 있습니다.

## 내 컴퓨터에서 먼저 해 보기

```
npm install
npm start
```

브라우저 탭 두 개로 `http://localhost:3000` 을 열고, 둘 다 "친구와 하기"에서 같은 코드를 입력하세요.

## 인터넷에 올리기 (Render 예시)

1. 이 폴더를 GitHub 저장소로 올립니다.
2. Render에서 New > Web Service로 그 저장소를 고릅니다. (`render.yaml`이 있어서 설정이 자동으로 채워집니다)
3. 배포가 끝나면 나오는 주소(`https://...onrender.com`)를 친구에게 보냅니다.

무료 플랜은 한동안 접속이 없으면 잠들고, 다시 열 때 30~60초쯤 걸립니다. 상시 켜 두려면 유료 플랜(월 7달러 안팎)이나 Fly.io 같은 곳을 쓰세요.

Fly.io를 쓰려면 이 폴더에서 `fly launch` 후 `fly deploy` 하면 됩니다. 포트는 `PORT` 환경변수를 자동으로 따릅니다.

## 구조

- `server.js`: 방 관리와 메시지 전달만 합니다. 판정은 하지 않습니다.
- `public/index.html`: 게임 전체. 주소와 같은 곳의 웹소켓으로 접속합니다.

## 알아 둘 점

- 방 코드를 아는 사람은 누구나 들어올 수 있습니다. 한 방은 최대 16명 접속, 한 판은 최대 8명입니다.
- 판정을 각 화면이 하기 때문에, 코드를 고쳐서 부정행위를 하는 사람을 서버가 막지는 못합니다. 친구끼리 하는 용도에 맞는 구조입니다.
- 서버는 메모리만 쓰고 아무것도 저장하지 않습니다. 재시작하면 방이 모두 사라집니다.
